# 0.32.0

- Project changes opens as a closable tab beside Terminal or Conversation instead of a modal. Switching tabs keeps the views mounted and retains selection, scroll position, and terminal processes.
- Add filename filtering, compact file rows with readable status labels, a draggable divider, colored diffs, and old/new line numbers.
- Separate uncommitted file counts from unpushed commit counts. Shared-folder attribution and local-reference limitations remain available.
- Start an agent review of all changes or the selected file from the Changes tab. Reviews continue to send instructions and scope only.
