# RunHuddle 0.17.0 — local preview

- Activity shows your latest request followed by the latest response, with a follow-up composer below.
- Connected Codex sessions accept text follow-ups through the supported queue command, using the existing session. Working sessions queue the message for their next turn.
- Drafts are saved per session. A queue receipt confirms acceptance, not completion. Unconfirmed delivery blocks retries until you check the terminal.
- Pending questions and approvals remain in the terminal. Claude and Copilot inline sending are not enabled in this preview.
