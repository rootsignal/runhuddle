# RunHuddle 0.20.4 — terminal preferences

Settings → Terminal now includes installed monospace fonts, text sizes from 9–32 pt, Follow app/Paper/Midnight/Warm color presets, six cursor styles, scrollback limits, and Option-as-Meta. A preview shows the selected font and colors. Command-plus/minus adjusts the shared text size; Command-zero resets it. Restore terminal defaults resets these preferences.

Changes apply without restarting agent processes. Lowering scrollback trims older terminal output, not saved agent history. External terminal controls remain below the embedded settings.
