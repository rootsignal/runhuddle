# RunHuddle 0.24.1

View options independently show the session list and Session info, with manual Refresh session data available in the same menu. View remains available when the session is expanded. Remove duplicate Prepare handoff from Session info.

Simplify session filters to Active, All, Pinned, and Archived. Active contains only agents running in RunHuddle; remove the Elsewhere navigation destination. Recorded history remains available in All.
