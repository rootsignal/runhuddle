# RunHuddle 0.16.0

- Compact activity breakdown in Now, with labeled status icons and a proportional snapshot bar.
- Context-usage rings, more readable metadata and agent badges, and titles that can wrap to two lines. Metadata adapts to narrow columns.
- Full-row disclosure controls with larger click targets and hover feedback throughout the workspace and settings.
- Consistent icon action sizes, clearer accessibility labels, and a terminal icon on the primary session action.
- Saved work uses the same selection treatment as sessions, cleaner previews, a framed editor, copy confirmation, and useful empty-state recovery actions.
- Switcher uses recognizable state icons and sizes itself to the session count and request content.
- Shorter guidance and status copy, explicit search clearing, and feedback for unmatched project filters.
- Open at login is available in General settings.

Validation includes native compilation, core tests, and offscreen production-component previews at wide/narrow widths in light and dark appearance. The previews use fictional data; they do not exercise live terminal interactions.
