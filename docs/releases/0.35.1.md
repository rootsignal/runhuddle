# 0.35.1

- Project note generation uses dedicated knowledge-capture instructions, separate from handoffs and reports. Default notes focus on the most recent substantive topic, with optional user focus.
- Generated notes supply a knowledge-oriented title and editable Markdown body. User-customized titles are retained. Empty or malformed titled output is rejected without saving.
- Capture offers Project note (default) or Session report. Reports preserve outcomes, verification, and unfinished work; notes omit transient chronology unless requested.
- Existing saved notes remain unchanged.

Validation includes Swift tests, Python prompt/response tests, and real Codex generation from the recorded RunHuddle session with default note, focused note, and report requests. See the generation evaluation for output-level findings.
