# RunHuddle 0.14.0

- Simplified session navigation to Now, Pinned, All sessions, and Archived. Saved work lives in its own Library section with independent tool/project filters.
- Search defaults to the current view, matching filter behavior. Search all sessions explicitly includes archived sessions while keeping tool/project selections.
- Replaced nested filter menus with a popover containing direct tool choices and a searchable project list.
- Renamed inactive history to Previous session and uncertain live status to Activity unconfirmed, with an explanation in details.
- Filtered empty states explain missing matches and offer Clear filters or View matching history.

Validation: full release suite, native build, standalone packaging and updater checks. Live UI interaction is not automatically tested.
