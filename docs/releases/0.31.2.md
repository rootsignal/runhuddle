# RunHuddle 0.31.2

Fix **command too long** when starting a review or handoff with a large initial prompt.

Persistent terminals now receive a short path to a private launch script instead of the entire prompt inside tmux’s command message. The login shell passes the original prompt directly to the selected CLI and uses exec to preserve agent PID tracking. Launch files are mode 0600 within RunHuddle’s private Application Support directory, remove themselves when started, and are removed if terminal creation fails. Provider arguments, literal quotes, Unicode, and trailing newlines are preserved. Existing review evidence-size limits are unchanged.

Validate the project directory before launch so tmux cannot silently fall back to a different folder. Regression checks exercise large prompts for Codex, Claude, and Copilot with local capture shims through the actual tmux path, including failure rollback, literal shell characters, and file cleanup. Agent sign-in and permissions are unchanged.
