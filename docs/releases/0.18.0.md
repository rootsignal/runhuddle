# RunHuddle 0.18.0

- Start a new Claude Code session with RunHuddle replies from the toolbar, or reconnect a saved conversation from its Activity tab.
- The launch sheet explains Claude's experimental channel consent and the difference between connected sessions and sessions started independently.
- Follow-ups and local image paths use an owner-only local channel bound to the exact Claude session. Approvals stay in the terminal.
- Conversation messages distinguish forwarded events from receipts acknowledged by Claude. Uncertain delivery is never retried automatically.
- Newly opened Claude sessions without transcripts show an empty conversation instead of a Python error.

Claude must be launched through the connected-session option; this cannot attach a channel to an already-running process. Exit an existing conversation in Claude before resuming it with replies. Claude may require consent for its development channel and receipt tool. Organization policies can block channels. No global Claude configuration or permission settings are changed.
