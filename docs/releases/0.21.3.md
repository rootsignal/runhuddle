# RunHuddle 0.21.3 — terminal drag and drop

Drop screenshot files, images, or the floating macOS screenshot thumbnail into an embedded terminal to insert file references. Images without an existing file are saved locally. Dropping does not submit the prompt. Clipboard image paste continues to work.

Validation: 70 Swift tests, embedded PTY checks for quoted paths, image references, control-character rejection and no automatic submission, and a successful app build. Live thumbnail dragging and each agent's image interpretation still require interactive validation.
