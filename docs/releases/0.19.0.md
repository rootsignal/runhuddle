# RunHuddle 0.19.0

- Copilot follow-ups through a local user extension. Enable once from New session or a Copilot session’s Activity view, then restart/resume existing Copilot sessions. Future sessions load the connection automatically.
- Replies target the connected foreground session. Copilot retains its model and permission settings; answer questions and approvals in its terminal.
- Slow upward scrolling immediately pauses conversation auto-follow. Return to the bottom or choose Latest to follow new activity again.

Copilot replies require a CLI version supporting SDK extensions. Delivery errors are never automatically retried. This connection has automated coverage; live delivery should be verified after restarting Copilot.
