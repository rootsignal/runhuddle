# RunHuddle 0.26.0 — independent appearance

Move app and terminal styling into a dedicated Appearance settings tab. App System/Light/Dark and accent are independent by default. Terminal themes retain their colors; optional app matching must be enabled explicitly. The one-time upgrade migration unlinks the formerly automatic matching without clearing terminal styling. Saved terminal themes preserve the matching choice and terminal behavior.

Keep scrollback and Option-as-Meta in Terminal settings, and startup, shortcuts, help, and updates in General. Replace clipped custom toolbar branding with the native window title.
