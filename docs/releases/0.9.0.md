# RunHuddle 0.9.0 preview

A quick session switcher in the menu bar keeps your terminals within reach.

- Click the owl or press Control–Option–Space to find active Codex, Claude Code, and Copilot sessions.
- Sessions are grouped by Needs you, Working, and Idle. Click a row to switch to its terminal; ambiguous matches still ask you to choose.
- Search, arrow keys, Return, and Escape work within the popover without changing the main window’s filters.
- Change, disable, or reset the global shortcut in RunHuddle → Settings → Session switcher. Your preference persists between launches.
- Open the full window for saved sessions, history, cleanup, and handoffs. Connections, appearance, updates, and Quit remain in the popover’s gear menu.

Validation: Swift build and 36 core tests; release pipeline validates Python integrations, standalone packaging, signing, and updater configuration. Interactive keyboard and multi-monitor behavior still need hands-on validation.
