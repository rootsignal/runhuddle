# 0.36.7

- Force UTF-8 output for RunHuddle's embedded tmux clients regardless of the locale inherited by the app. This addresses non-ASCII symbols appearing as underscores.
- Apply the same UTF-8 setting when attaching to existing persistent sessions. No shell-profile edits or tmux server restart are required; the app reconnects its terminal clients after updating.

Validated the production tmux attachment arguments under an explicitly ASCII locale, plus new/resumed agent launches across zsh, bash, and tcsh. Output already emitted as underscores by an application itself cannot be reconstructed by this setting.

Corresponding source, including pinned Swift package dependency sources and build scripts, is provided in `RunHuddle-0.36.7-source.tar.gz` alongside this installer. See docs/BUILDING.md and docs/LICENSING.md in that archive.
