# 0.33.0

- Add Open terminal in the New session dropdown, with a working-folder picker and the user's macOS login shell.
- Shell terminals have distinct sidebar entries, editable names, folder actions, and End terminal. They do not show agent checklists, context usage, resume, archive, or handoff actions.
- Shell identity, environment, and running processes survive app closure through the existing private tmux runtime. Starting an AI CLI manually does not turn the shell into an agent entry.
- Shells participate in Active/All navigation, project filters, search by name/folder, and the Shell tool filter. The quit dialog includes shells when offering to keep terminals running.
