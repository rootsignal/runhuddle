# 0.35.0

- Saved work is now Notes. Existing records keep their identity, content, provenance, and Markdown export; no storage migration or deletion is required.
- Session Info opens project-scoped notes and offers Save as project note, with an optional capture focus for generation. All notes remains available across projects.
- Notes support Markdown editing, search, source-session navigation, and Use in a new session.
- New session can explicitly include selected notes from its project. Review and edit the exact first prompt before launch. Switching projects clears the selection; no notes are included by default.
- Using a note treats it as reference knowledge, including older saved handoffs, without secretly prepending continuation instructions.

This is the project-notes and reuse foundation, not a replacement for the full workspace navigation. Pinned notes and reviewed versioned updates remain future work.
