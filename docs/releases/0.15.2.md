# RunHuddle 0.15.2

- Saved work now opens in the main workspace with a list and detail pane. Start a fresh Codex, Claude Code, or Copilot session from a reviewed saved summary.
- Generate handoffs or draft work summaries for multiple selected sessions. Review generated summaries before saving them to the library.
- Session context menus now include handoff generation and archiving. List icons show generated handoffs, saved work, and observed compaction counts, with a collapsible icon guide.
- Track observed compactions from available Codex, Claude Code, and Copilot history. Counts describe recorded events, not guaranteed lifetime totals.
- Choose Terminal, iTerm2, or Ghostty and a new tab or window for session launches. Terminal tab targeting handles changed window identities and slower shell startup while refusing ambiguous targets.
- Renaming an active session can update its uniquely matched Terminal tab title.
- Consolidated sidebar controls into Settings with General, Connections, Terminal, and Notifications tabs.
- Temporary project folders are grouped under Temporary / other in filters.

Terminal.app tab creation requires Accessibility permission. iTerm2 and Ghostty use native scripting; Ghostty requires 1.3 or later with AppleScript enabled.

Validation includes Swift and Python tests, simulated Terminal tab targeting, standalone packaging, and updater checks. Live terminal interaction is not automatically tested.
