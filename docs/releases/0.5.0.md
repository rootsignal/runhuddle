RunHuddle 0.5.0 makes active work easier to find and adds signed in-app updates.

- **Now** opens on sessions needing input, work in progress, recently finished sessions, and idle sessions. Saved history stays in All sessions; searching from Now also searches saved sessions.
- **Pinned sessions** and an exact project-folder filter keep important work close.
- Cleaner rows show a compact provider badge and a short recorded activity excerpt. Notes and technical details are expandable; the version remains visible in the sidebar.
- Connection warnings are quieter, with details and recovery actions in Connections. Terminal actions distinguish locating a terminal from resuming a saved session.
- **Check for Updates…** downloads, installs, and relaunches in place using Sparkle. Automatic checks are opt-in in Connections, and installation remains your choice.

Install this version once using the DMG if you are on 0.4.x. Quit RunHuddle before replacing the app in its existing Applications folder. Confirm **0.5.0** in the sidebar. Names, notes, handoffs, and hook paths at the same app location are preserved.

The app and installer are Developer ID signed and notarized. Update archives and the update feed have EdDSA signatures. Validation includes 63 Python tests, 25 Swift tests, standalone relocation and signing checks, and an isolated integration test that rejects a modified feed and successfully downloads, installs, and relaunches a valid update. GitHub CI passes.

Requires Apple Silicon and macOS 14 or newer. Activity excerpts come from recorded messages; AI-generated summaries are not enabled. Claude processes that themselves report stale busy status remain a separate diagnostic issue.
