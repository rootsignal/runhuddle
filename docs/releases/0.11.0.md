# RunHuddle 0.11.0 preview

Session details now include a compact repository context section:

- Current branch or detached HEAD, main/linked worktree, and worktree path.
- Changed-file count including staged, unstaged, and untracked files.
- Explicit shared-state labeling: repository changes are not attributed to one agent.
- Local, read-only inspection when opened, with manual refresh and a snapshot timestamp. No background Git polling.

Missing or inaccessible repositories are handled quietly. PR and CI integration will follow separately.

Validation includes real temporary Git repositories, unborn and detached branches, linked worktrees, rename/newline filename parsing, and missing folders, plus light/dark component rendering. Full release checks cover Swift/Python tests, standalone packaging, and the updater.
