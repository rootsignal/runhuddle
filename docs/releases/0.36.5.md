# 0.36.5

- Reduce repeated session-list grouping and search work during refreshes.
- Avoid database WAL writes when saved content is unchanged, and avoid replacing identical recorded history solely to update its retrieval timestamp.
- Move recurring terminal status queries off the UI thread and stop polling ended terminals.
- Apply terminal appearance settings only when preferences or appearance change.
- Include GPLv3 licensing and notices. Earlier MIT permissions are not revoked.

Build and 100 Swift tests passed, including unchanged-write and transaction rollback regression tests. These changes address identified sources of UI stalls; the reported CPU bursts on the affected Mac still need post-update verification.

Corresponding source, including pinned Swift package dependency sources and build scripts, is provided in `RunHuddle-0.36.5-source.tar.gz` alongside this installer. See its README and docs/BUILDING.md for build instructions and docs/LICENSING.md for licensing details.
