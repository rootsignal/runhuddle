# RunHuddle 0.12.0 preview

Main-window search now searches everywhere by default, including archived sessions.

- Match active, saved, disconnected, and archived sessions across all agents and projects.
- Use the new Current view scope to respect the selected sidebar view, agent, and project filters.
- Search results show their scope explicitly, and archived matches retain their Archived label.
- Done, Escape, or clearing the query returns to the selected view. Each new search defaults to Everywhere.

Titles, project details, notes, and available recorded conversation history remain searchable. Permanently deleted histories are not restored or searched. The menu-bar switcher remains focused on active sessions.

Validation covers all session states across Codex, Claude, and Copilot, current-view filter combinations, and unchanged non-search browsing behavior. The release pipeline checks the full Swift/Python suite, packaging, signed updates, and notarization.
