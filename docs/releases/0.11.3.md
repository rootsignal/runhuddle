# RunHuddle 0.11.3 preview

Bring useful context into view without scrolling past conversation excerpts.

- Compact session header and terminal actions.
- Branch and changed-file count stay above the activity scroll area, including while viewing Handoff.
- Worktree type and shared-state label remain visible; expand for path, check time, and explanation.
- Needs input requests lead the Overview activity area.
- Latest response previews are limited to three lines; full messages remain expandable.
- Notes and technical details remain collapsed. Shorter Now heading and tighter activity metadata reduce wasted space.

Includes the responsive workspace layout from 0.11.2. Verified by compilation and offscreen renders of the production layout and repository/response components at wide and narrow widths. Release validation covers the full test suite, standalone packaging, updater verification, and Apple notarization.
