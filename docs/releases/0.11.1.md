# RunHuddle 0.11.1 preview

Fix window resizing so the content stays within the available width.

- Tie the native window minimum to the content minimum, preventing the window from shrinking underneath its layout.
- Reduce the minimum width to 900 points and let the session list and details columns shrink further.
- Wrap terminal actions onto a second row when the details column is narrow.

Includes the repository context section introduced in 0.11.0. Validated by compilation and the release test suite; interactive multi-monitor resizing still needs confirmation on the affected setup.
