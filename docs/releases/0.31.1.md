# RunHuddle 0.31.1

Give **Start a review with another agent…** its own review flow instead of repurposing the handoff editor.

Choose the reviewer, select current uncommitted files, and optionally provide a review focus and brief task context. **Preview request…** displays the exact request. **Start review** sends a timestamped repository snapshot and bounded selected diffs directly to a new embedded session, asking for findings with severity and file references, without edits. No handoff generation, summary-agent picker, or recorded conversation history is involved. It works without an existing handoff, and does not alter saved handoff drafts.

Reviews use the current project folder. The HEAD-only isolated-workspace option is removed from this flow because it omits the uncommitted work under review. Normal agent permissions still apply; the no-edit instruction is not an enforced filesystem sandbox. The source remains linked as **Review of**, and independent reviews do not hide the original session.

Empty scopes are blocked. Users can select up to 200 files per review; unavailable and truncated evidence is explicitly identified. Refresh reloads the current changes, and selection/focus/context edits invalidate any prepared request. Full continuation handoffs retain their existing separate editor.
