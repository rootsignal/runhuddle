The Now view puts sessions needing input first, with a prominent attention panel and terminal action for Codex, Claude Code, and Copilot CLI. Working and idle counts stay visible, and session details open when you select a row, leaving more room to scan your work.

Session rows are more compact, with quieter selection and fewer borders. Saved and archived sessions live under History in the sidebar; disconnected sessions remain directly visible. The detail pane emphasizes the latest response and lets you expand the latest request when needed.

This release does not add in-app replies or approvals. Questions, choices, permissions, and written responses continue through the agent’s terminal. No request is inferred from recorded conversation text.
