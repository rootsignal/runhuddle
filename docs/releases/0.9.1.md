# RunHuddle 0.9.1 preview

Closed terminal sessions update sooner.

- macOS process-exit events now trigger agent status refreshes for recognized terminal CLIs and verified Claude/Copilot session processes.
- Follow-up checks after 1, 4, and 10 seconds accommodate delayed disconnect detection by shared agent servers. Multiple closures are coalesced.
- An exit never directly overrides a session’s status. Shared sessions and background work remain governed by the agent’s live snapshot.
- Existing agent events and the 30-second fallback remain in place for unidentified processes and missed events.

Validation: 39 Swift tests, including a real child-process exit and watcher cancellation; Python integration tests and signed standalone packaging checks run in the release pipeline.
