# RunHuddle 0.15.3

- Archived now shows transcript disk usage for the displayed sessions, alongside session and project counts.
- Session details show primary transcript file size, allocated disk space, and measurement age for Codex, Claude Code, and Copilot.
- Shared transcript files are counted once; unavailable files are reported explicitly. Measurements use file metadata without reading conversation contents.

Storage figures exclude project files, attachments, agent indexes, and saved-work records. APFS blocks may be shared, so allocated space is not necessarily reclaimable space.

Validation: Swift and Python tests, native build, standalone packaging, and updater checks.
