RunHuddle 0.7.0 refreshes the session workspace and makes search easier to find and leave.

- A clearer search field with a magnifying-glass icon, stronger contrast, a focus outline, and Command-F.
- Clear search with the field’s × button or Escape. Back to Now returns to active sessions; selecting any sidebar view also clears the query.
- A navy-and-cyan palette in dark mode and a coordinated light appearance, with a clearer sidebar and quieter counts.
- Session cards with an outlined selection, hover feedback, readable status badges, and clearer title/project hierarchy.
- Separate request and response cards in the detail panel. The repeated response preview is removed; a user-maintained purpose appears when provided.
- Markdown is cleaned from compact previews and rendered in expanded messages.
- Arrow-key navigation and bulk selection remain available. Tool and project filters are preserved when leaving search.

Validation: Swift/Python regression suites, rendered shared components in light and dark appearances, standalone package and updater checks. Full native keyboard and multi-monitor interaction was not automated in this environment.
