# RunHuddle 0.20.0 — local terminal prototype

- New Codex sessions can run inside RunHuddle using a native SwiftTerm pseudo-terminal. Input, streaming output, resizing, and Codex’s own approval interface are interactive.
- The embedded session window offers Terminal and Activity views. Reopen windows from the Terminals toolbar menu; closing a window keeps the process alive.
- Previous Codex conversations can be resumed inside RunHuddle from their Terminal tab. Already-running external terminals cannot be taken over.
- Quitting asks before ending embedded Codex processes. Processes do not survive an app quit or crash in this prototype. Recorded Codex conversation history can be resumed later; terminal scrollback is in memory only.

This is a local prototype, not a published release. Claude and Copilot continue to use their existing terminal/channel integrations. Image clipboard behavior has not been validated in the embedded terminal.
