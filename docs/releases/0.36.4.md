# 0.36.4

- Replace the app and menu-bar logo with three stacked terminal panes and a prompt, designed to stay recognizable at notification size.
- Handoffs default to the current folder and exclude their original session from warnings about other agents. Idle sessions no longer block the handoff; isolation remains optional.
- Label unresolved questions and next steps as optional, with clearer guidance when the original agent is still working.
- Refresh macOS application registration after local installation so system surfaces can pick up the app icon.

Built-in agent integrations currently support Codex CLI, Claude Code, and GitHub Copilot CLI. Other commands can run in shell terminals; that alone does not provide session tracking or other provider-specific integrations.
