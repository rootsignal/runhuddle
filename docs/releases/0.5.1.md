RunHuddle 0.5.1 makes terminal navigation and session cleanup easier to follow.

- Terminal’s chooser now includes tabs running through shells or wrappers, with live terminal matches ranked first and title matches clearly labeled.
- Opening Terminal shows progress without blocking the app. Automation permission errors include a shortcut to settings.
- Detached sessions explain that their current activity is unconfirmed.
- Bulk cleanup reports review and processing progress. Selection controls fit narrower lists, and cleanup results can be dismissed.
- Connections scrolls on smaller screens while keeping its action buttons visible.

Validation: Swift and Python regression suites, standalone bundle verification, and signed updater installation test. Physical multi-monitor and Ghostty interaction testing remains pending.
