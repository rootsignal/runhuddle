# 0.34.0

- Group shell terminals under one Terminals sidebar entry. Open shells appear as selectable, closable tabs in that workspace.
- Add a new-terminal button beside the tab strip, defaulting to the current shell's folder. Duplicate default names receive a numeric suffix.
- Closing a running tab asks before ending its shell and attached commands. Closing the selected tab selects another shell; closing the last leaves an empty terminal workspace.
- Linked AI conversations still select their existing shell tab. Shell processes and terminal history remain persistent; no split panes or drag reordering in this release.

- Closed conversations have a Resume this session action in their header, available with Session Info hidden.
