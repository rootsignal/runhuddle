# RunHuddle 0.22.0 — persistent terminals

Agents run in a private terminal server independent of the RunHuddle interface. Close RunHuddle and keep agents running, then reconnect to the same processes and terminal history. In-app updates keep agents running automatically and reopen the workspace. End sessions and quit remains available. A Mac restart still ends processes.

This release also adds softer terminal themes and live color controls, linked handoff chains with collapsible predecessors and reviewed archiving, and corrections to closed-session labels and stale Idle status.

The transition from older builds requires a one-time conversation resume because their processes cannot be detached. Subsequent updates retain persistent sessions. tmux and its runtime dependencies are bundled; users do not need Homebrew.

Validation includes Swift tests, real PTY detach/reattach and client-crash recovery with unchanged agent PID and shell state, retained terminal history, independent stopping of multiple sessions, and standalone package relocation and signature checks. Full signed-feed publication is separate from this local installation.
