# RunHuddle 0.16.1

- Session panels now use Activity, Handoff, and Details tabs.
- Activity keeps the latest response, request, and editable notes together.
- Details contains repository state, context, compactions, transcript storage, and session identifiers.
- The header shows a compact branch/change-count link that opens Details. Both displays share one repository snapshot.
- Switching to Details or Handoff no longer triggers an activity-history refresh.
