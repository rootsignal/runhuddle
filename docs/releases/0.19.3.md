# RunHuddle 0.19.3 preview

This preview brings the local conversation workspace and agent reply connections to the downloadable release.

- Read recent conversation messages and send follow-ups from Activity, with an expandable conversation view, saved drafts, image-path previews, a working indicator, and a Latest shortcut.
- Slow upward scrolling pauses auto-follow immediately. Return sends; Shift-Return adds a line.
- Codex replies queue into the connected session. Claude replies use a connected launch through RunHuddle and may require terminal consent.
- Starting Copilot from RunHuddle installs its reply extension and enables experimental extension support for that launch. Reconnect with replies resumes the same conversation after gracefully closing a verified idle Copilot process.
- New session supports detected Codex, Claude Code, and Copilot installations.
- Activity, Handoff, and Details tabs, larger disclosure targets, improved metadata, context rings, state icons, and clearer saved-work layouts.
- Improved terminal matching for sessions waiting on input.

## Preview limitations

Questions and approvals remain in the agent’s terminal. Copilot replies use experimental SDK extensions; automated checks pass, but live end-to-end reply delivery has not yet been confirmed on the current Copilot setup. Claude channels can be restricted by organization policy. Local image references must exist on the Mac running the session; they are not synced between Macs.

The download is for Apple Silicon Macs running macOS 14 or newer. RunHuddle includes its Python runtime; install and sign in to the coding agents separately.
