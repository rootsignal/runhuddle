# 0.36.8

- Replace per-terminal one-second status polling with process exit events and shared reconciliation triggered by provider and terminal events. A batched check every 30 seconds catches missed events.
- Keep live terminals open when a status query fails; require process-exit evidence before marking them closed.
- Move session search into the session sidebar. Command-F reveals the sidebar and focuses search.

Validated with 103 Swift tests and terminal integration checks covering batched status, process exit notifications, and preservation of sibling terminals. CPU improvement on the affected Mac still requires measurement; this release does not claim to resolve all UI refresh overhead.

Corresponding source, including pinned Swift package dependency sources and build scripts, is provided in `RunHuddle-0.36.8-source.tar.gz` alongside this installer. See docs/BUILDING.md and docs/LICENSING.md in that archive.
