# RunHuddle 0.28.0

Make Session info focus on project access, current repository status, continuation, history, and notes. Move diagnostic metadata into Details, remove repeated project fields and unavailable context/storage placeholders, and show context usage only when reported. Read repository state when the pane opens rather than for every selected terminal.

Add preferred project editor selection in Settings → General. Detect common installed editors, prefer VS Code automatically, and allow choosing another application. Open the session’s working directory in the chosen editor from Session info or the session action menu. Missing folders and unavailable editors show an actionable error instead of silently opening another editor.
