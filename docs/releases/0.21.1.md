# RunHuddle 0.21.1 — external sessions

Running here shows only active sessions owned by RunHuddle. Running elsewhere has its own sidebar destination and count, with read-only activity and a clear Running outside RunHuddle label. All sessions and Pinned continue to include non-archived conversations from either location.

Go to external terminal focuses an existing window/tab/pane. If the match is ambiguous, a focus-only picker lets you choose; it never offers to start or resume externally. New and inactive sessions still launch inside RunHuddle.
