# RunHuddle 0.13.0 preview

Preserve useful AI work independently of the original conversation with the new Saved work library.

- Save a manual or AI-generated work summary from session actions. Review before saving.
- Preserve an existing edited handoff as a separate library snapshot.
- Search and edit saved records, copy them, or export Markdown with source metadata.
- Session deletion keeps independent records and offers Save summary first.
- Explicit library deletion removes only the selected record after confirmation.

Generation reuses the isolated signed-in CLI workflow. No automatic background AI usage, cloud sync, or memory injection. Library search is separate from session search. Records preserve source IDs, project, dates, generator attribution, and caveats; they are not full transcript backups.

Validation: independent persistence through source removal and database reopen, snapshot identities, search/export provenance, and work-summary prompt constraints; light/dark offscreen composer/library review. The existing isolated generation commands remain unchanged; no new live paid-generation test was run. Release checks include full Swift/Python tests, standalone packaging, updater verification, and notarization.
