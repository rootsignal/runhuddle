# RunHuddle 0.25.0 — terminal themes

Ship Dracula, Nord, Catppuccin Mocha, and Solarized Light using their published terminal palettes, plus coordinated RunHuddle workspace colors. Include source credits and MIT notices.

Add a real SwiftTerm preview; individual ANSI, cursor, selection, and accent overrides; saved custom themes; per-color and preset resets; and a text/background contrast readout. Existing font and terminal preferences migrate. Theme changes apply to open terminals without restarting agents. Explicit agent RGB colors remain intact.

Also includes removal of the redundant Recorded preview from Session info, prepared in 0.24.3.

See docs/THEMES.md for color behavior, sources, and validation limits.

Use standard xterm values for extended 256-color output, avoiding unintended theme-derived hue shifts in agent interfaces.
