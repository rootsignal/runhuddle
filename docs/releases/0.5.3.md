RunHuddle 0.5.3 adds event-driven activity updates and fixes sidebar navigation.

- Codex uses a persistent, passive app-server connection to receive status and lifecycle changes. RunHuddle never starts, resumes, or subscribes to a thread merely to monitor it.
- Claude and Copilot hooks signal RunHuddle after saving meaningful state changes. Repeated working events do not repeatedly refresh the UI.
- Events refresh only the affected provider. Bursts are combined, and events arriving during another refresh or cleanup remain queued.
- A quiet 30-second reconciliation check catches missed hooks, terminated processes, and older sessions. Codex reconnects automatically after disconnection.
- Background checks no longer grey out the refresh button. Manual refresh retains progress feedback.
- Click anywhere in a sidebar filter row, including the count or empty space, to switch views.

Existing hooks pointing to the same installed app path use the updated collector automatically. Sessions with no hooks remain covered by reconciliation; restart/resume them after tracking setup if live hooks are not loaded.

Validation includes real macOS file-notification tests, hook commit/signal tests, a passive-observer test against an isolated Codex server without an AI prompt, regression suites, standalone packaging, and signed updater checks. Live Claude/Copilot agent testing on the other Mac remains useful.
