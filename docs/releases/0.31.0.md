# RunHuddle 0.31.0

This release delivers a first version of the six workspace improvements discussed after the product comparison.

- **Lifecycle:** Ended terminals show Session ended with conversation/resume actions and optional terminal output. End and archive stops only the selected agent, then opens archive review after it exits. Unknown live status is explicitly labeled; Session Info distinguishes idle/open from closed. Existing terminal and sidebar restoration remains in place.
- **Project changes:** Click the Repository card’s changed-file count to inspect filenames, line counts, and read-only diffs, or open a file in the preferred editor. Branch and upstream comparison are shown separately from uncommitted changes. Comparisons use local Git refs, without fetching, and cannot establish the current remote state. Large/binary files have explicit preview limits. Changes belong to the project, not one session.
- **Attention inbox:** A compact inbox beside navigation keeps unread completion results and unexpected owned-agent exits. Input requests are derived from current agent state and stay pending after opening. Results can be marked read by opening the session. Entries and last observed states persist locally; monitoring does not manufacture events from missing data.
- **Project preferences:** Project shortcuts in Session Info configure a preferred agent/editor, HTTP(S) links, a handoff note, and optional Run app, Run tests, and Build commands. Commands start blank and run only after explicit review. Output is bounded; Stop targets the command’s own process group. Project commands stop when RunHuddle closes.
- **Parallel work:** New-session, saved-work, and handoff launch reviews identify an already-open project and require choosing shared access or an isolated Git worktree. The new branch and folder are shown before launch. Worktrees start from HEAD and do not copy uncommitted files. A workspace created before a launch failure is retained and identified, never silently deleted.
- **Cross-agent handoffs:** Reviews include an editable timestamped repository snapshot, separate unresolved questions and next steps, and the project note. Start a review with another agent includes a bounded, reviewable project diff and asks for findings without edits. Continued, reviewed, and branched sessions have distinct source links; reviews/branches do not hide their source as a continuation. Additional reviewed context is also included in copy/export/save actions.

Also replaces the distant icon-only new-session control with a labeled button beside Sessions, explains the absence of a structured agent checklist, and darkens gray message backgrounds in Midnight/Slate/Dusk. Official third-party palettes and explicit agent RGB colors remain unchanged.
