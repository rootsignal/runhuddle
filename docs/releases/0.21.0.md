# RunHuddle 0.21.0 — one terminal workspace

New sessions, resumed conversations, handoffs, and saved-work launches now use the embedded terminal for Codex, Claude Code, and GitHub Copilot. No development channels or reply extensions are needed for terminal input; normal authentication, permissions, and organization policies apply.

The running terminal appears in session details with expand/collapse, Handoff, and Details. Expanding keeps the same process, input, and output. The duplicate Activity composer and separate Terminals sidebar section are removed. Undetected startup terminals remain reachable in the list and toolbar menu.

External sessions remain visible with read-only Activity. Exit them in their original terminal before resuming in RunHuddle. External launch settings and terminal discovery dialogs are removed from the user flow.

End session now shows Stopping and terminates the owned process group, escalating if it ignores the initial request. Quit waits for that shutdown before exiting. Closing an exited terminal retains recorded agent history.

Clipboard images are stored privately as local PNG files and pasted as file references without submitting the prompt. Interpretation depends on the agent/model. Font, theme, cursor, scrollback, and keyboard preferences remain available in Settings.

Validation: Swift tests and native PTY tests cover resize, reparenting, live preferences, exact resume arguments for all three providers, prompt quoting, and termination escalation. Live Claude/Copilot conversations and approval/image behavior still require interactive validation. This remains a local preview; processes and scrollback are not persistent across app quit or crashes.
